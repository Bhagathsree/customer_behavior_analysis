# 📊 Customer Behavior Data Analysis

## 📌 Overview

This project focuses on analyzing customer behavior using **Python, MySQL, and Power BI**. The project follows a complete data analytics workflow, starting from data loading and cleaning to exploratory data analysis, SQL-based analysis, dashboard creation, and business reporting.

The goal is to identify meaningful **customer trends, purchasing patterns, and key business insights** from the dataset and present them through an interactive Power BI dashboard and analytical report.

---

## 📂 Dataset

The dataset contains customer-related information that can be used to analyze purchasing behavior and customer characteristics.

The analysis includes areas such as:

* Customer demographics
* Purchase behavior
* Product/category information
* Sales-related information
* Customer preferences and trends

## 🔄 Project Workflow

The project follows these major steps:

### 1. Data Loading

* Loaded the dataset into Python using Pandas.
* Inspected the dataset structure.
* Checked rows, columns, data types, and basic statistics.

### 2. Exploratory Data Analysis (EDA)

Performed exploratory analysis to understand the dataset and identify important patterns.

Key activities included:

* Understanding data distributions
* Analyzing categorical and numerical variables
* Identifying trends and patterns
* Checking relationships between variables
* Creating visualizations to support analysis

### 3. Data Cleaning

The dataset was prepared for further analysis by:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Cleaning inconsistent values
* Formatting columns where required
* Validating the final dataset

### 4. SQL Analysis

The cleaned data was loaded into **MySQL Server** for structured analysis.

SQL queries were used for:

* Filtering data
* Aggregating information
* `GROUP BY` analysis
* `ORDER BY` analysis
* Conditional analysis
* `JOIN` operations where required
* Finding business-related insights

### 5. Power BI Dashboard

The analyzed data was connected to **Power BI** to create an interactive dashboard.

The dashboard includes:

* KPI cards
* Charts and graphs
* Customer behavior analysis
* Category-wise analysis
* Trend analysis
* Interactive filters and slicers

### 6. Report Preparation

A detailed project report was created to document:

* Project objectives
* Dataset description
* Data preparation
* EDA findings
* SQL analysis
* Dashboard insights
* Business findings
* Conclusion

### 7. Presentation

A project presentation was created using **Gamma** to summarize the analysis, findings, dashboard, and key business insights in a clear presentation format.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/customer-behavior-data-analysis.git
```

### 2. Open the Python Notebook

Open:

```text
notebooks/customer_behavior_analysis.ipynb
```

Run the notebook using **Jupyter Notebook or JupyterLab**.

### 3. Install Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 4. Set Up MySQL

* Install and start **MySQL Server**.
* Open **MySQL Workbench**.
* Create the required database.
* Import/load the cleaned dataset.
* Run the SQL queries from the `sql` folder.

### 5. Open the Power BI Dashboard

Open the `.pbix` file located in:

```text
powerbi/
```

If necessary, update the data source connection.
